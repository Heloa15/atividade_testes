# 🚗 Lavagem Automotiva

Sistema web para uma empresa de lavagem automotiva, desenvolvido para permitir que clientes conheçam os serviços, consultem planos, agendem uma lavagem e adicionem produtos ao carrinho.

## 📋 Sobre o projeto

O projeto consiste em uma aplicação web para gerenciamento e apresentação de serviços de lavagem automotiva.

A aplicação possui uma interface para clientes e uma API responsável pelo gerenciamento dos dados.

### Funcionalidades

- 🏠 Página inicial
- 🚘 Apresentação dos serviços
- 💎 Planos de lavagem
- 📅 Agendamento de lavagem
- 🛒 Carrinho de produtos
- 🔎 Busca de produtos
- 🗑️ Exclusão de produtos do carrinho


## 🛠️ Tecnologias utilizadas

### Front-end

- HTML
- CSS
- JavaScript

### Back-end

- Node.js
- Prisma 

### Banco de dados

- Banco de dados configurado através do Schema Prisma
